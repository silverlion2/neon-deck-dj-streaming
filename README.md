# NEON DECK · DJ Streaming 助手

赛博朋克霓虹风格的 DJ 直播全链路助手，覆盖直播动效、弹幕互动、DJ 控制台、多平台对接等完整场景。

## ✨ 功能特性

### 直播核心
- **音频反应可视化**：环形频谱 / 波形 / 粒子喷射三种模式，随 BPM 节拍脉冲
- **Web Audio 合成引擎**：真实鼓机音效（Kick/Snare/Hat/Clap/Bass/FX），4 套音色预设（Techno/Acid/Trap/Synthwave）
- **虚拟 DJ 控制台**：双转盘、推子、交叉推子、BPM、AutoDJ 自动过渡
- **8 格音效垫**：键盘映射（1234/QWER），Loop 录制回放

### 互动与变现
- **弹幕系统**：飘浮弹幕墙、发送弹幕、礼物面板、@提及
- **互动游戏**：猜歌名 / BPM 竞猜 / 弹幕抽奖
- **变现系统**：付费点歌插队、打赏目标进度条
- **观众留存**：进场欢迎动效、等级徽章、贡献榜
- **歌词同步**：卡拉OK式歌词流叠加

### 平台深度对接
- **多平台支持**：抖音 / 小红书 / 哔哩哔哩 / 快手 / 通用
- **OAuth 授权连接**：模拟授权流程，预留真实 API 接入点
- **RTMP 推流配置**：一键复制 OBS 配置（地址/码率/编码器/分辨率）
- **多平台同播**：同时推流状态、各平台观众数、一键开播下播
- **合规过滤**：按平台差异化敏感词库、自动屏蔽、弹幕测试

### 数据与运营
- **实时热度曲线**：弹幕/礼物/点赞叠加活动曲线
- **直播数据面板**：峰值在线、热门曲目、曲目反响评分
- **精彩时刻标记**：一键打点高光，事后回放
- **智能选曲**：BPM + 调性(Camelot Wheel)匹配推荐
- **能量曲线**：整场播放能量走势

### 视觉定制
- **4 套主题配色**：霓虹紫青 / 极光翠绿 / 熔岩暖橙 / 深海蓝
- **主题夜一键切换**：配色+预设+曲库联动
- **冷场检测预警**：弹幕密度走低时自动提醒
- **多画面布局**：全功能/舞台特写/弹幕沉浸/极简输出

## 🛠 技术栈

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** 自定义霓虹设计系统
- **Zustand** 状态管理（12+ stores）
- **Web Audio API** 实时音频合成
- **Canvas 2D** 高性能可视化

## 📁 项目结构

```
src/
├── audio/          # Web Audio 合成引擎 + 音色预设
├── components/     # UI 组件（25+ 模块）
│   ├── Analytics/  # 数据复盘
│   ├── Audience/   # 观众留存
│   ├── Chat/       # 弹幕互动
│   ├── Deck/       # DJ 控制台
│   ├── Games/      # 互动游戏
│   ├── Host/       # 主播工具
│   ├── Platform/   # 平台对接
│   ├── Stage/      # 直播舞台
│   └── Vibe/       # 氛围与布局
├── data/           # 模拟数据（曲目/平台/弹幕/礼物）
├── hooks/          # 节拍引擎 + 可视化
├── store/          # Zustand stores（12+）
└── utils/          # 工具函数
```

## 📝 平台对接说明

各大直播平台需后端代理 OAuth + WebSocket 弹幕协议。当前采用模拟授权 + 真实配置参数，`useIntegrationStore` 的 `authorize()` / `goLive()` / `filterDanmaku()` 为真实 API 替换点。RTMP 地址和编码参数均为各平台真实推荐值，可直接用于 OBS 配置。
